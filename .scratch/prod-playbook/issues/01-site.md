## Commands

Run from the repo root. The README lists 3 to 6 for everyday use.

1. `uv sync`: makes `.venv` with MkDocs Material 9.7.7, literate-nav, pre-commit and commitizen from `pyproject.toml`.
2. `.venv/bin/pre-commit install`: installs the hooks, gitleaks among them (PP-Q6).
3. `rm -rf imported && mkdir imported && git -C ../src archive "$(sed -n 's/^  src_commit: //p' docs-site/mkdocs.yml)" infra | tar -x -C imported && find imported -type f ! -name '*.md' ! -name '*.svg' -delete`: imports the infra pages and their rendered diagrams (src's Documentation standard, 683a17b) at the named src commit into `imported/`, which git ignores (PP-Q7).
4. `c=$(sed -n 's/^  src_commit: //p' docs-site/mkdocs.yml) && t=$(mktemp -d) && git -C ../src archive "$c" infra lib | tar -x -C "$t" && "$t/infra/net/catalog" "$t/infra/net/prod.conf" && cp ~/.local/share/agentic-workflows-prod/catalog.html imported/ && rm -rf "$t"`: regenerates the catalog with net's script at that commit and the read-only token, and copies it into `imported/` (PP-Q8).
5. `uv run mkdocs build --strict -f docs-site/mkdocs.yml -d "$(git rev-parse --show-toplevel)-site"`: builds the site beside the repo, failing on any warning; imported pages' links to src files the playbook lacks become plain text (`docs-site/hooks.py`, PP-Q19).
6. `uv run mkdocs serve -f docs-site/mkdocs.yml`: serves it at http://127.0.0.1:8000 on this machine (PP-Q9, PP-Q15).

Verified by running 1 to 6 here and showing the user a render before the commit (rule 9).
